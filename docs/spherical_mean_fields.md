# Spherical Coulomb mean fields

`tdmcscf.grid.spherical` constructs the Coulomb potential generated by each
requested orbital pair and applies it to other orbitals. It supports general
spherical-harmonic expansions and a polar-only path for fixed-m orbitals.

## Representation

Atomic units and orthonormal complex spherical harmonics are used:

$$
\phi_p(r,\Omega)=\frac1r\sum_{lm}u^p_{lm}(r)Y_{lm}(\Omega).
$$

An orbital array has shape `(n_orbitals, n_r, n_lm)` and contains **nodal
values** of the reduced radial functions $u^p_{lm}(r_a)$. It has no absorbed
square-root quadrature weights. The radial axis excludes the first and last
nodes of the supplied radial grid. The nodal cardinal basis has quadrature
metric $S_{ab}=w_a\delta_{ab}$, so orbital overlaps are

$$
\langle\phi_q|\phi_p\rangle\approx
\sum_{a,lm}w_a[u^q_{lm}(r_a)]^*u^p_{lm}(r_a).
$$

`builder.orbital_lm` gives each orbital channel's `(l, m)`. The order is
M-major, matching `grid_lib.spherical_coordinates.angular_momentum.LM_to_I`.
`builder.multipole_lm` gives the retained field channels. By default they
extend to `L_max = 2*l_max` and `M_max = 2*m_max`; pass smaller `L_max` and
`M_max` values to truncate the Coulomb expansion explicitly.

The field convention is

$$
W_s^q(\mathbf r)=\int d^3r'\,
\frac{\phi_q^*(\mathbf r')\phi_s(\mathbf r')}{|\mathbf r-\mathbf r'|}
=\sum_{LM}W_{qs}^{LM}(r)Y_{LM}(\Omega).
$$

With $U_p=r\phi_p$, the reduced pair multipoles and their radial response are

$$
d_{qs}^{LM}(r)=\int d\Omega\,Y_{LM}^*(\Omega)U_q^*(r,\Omega)U_s(r,\Omega),
\qquad W_{qs}^{LM}(r_a)=\sum_b K_L[a,b]d_{qs}^{LM}(r_b).
$$

`K_L` is obtained from grid-lib's `radial_Coulomb`. It already contains
source radial weights and $4\pi/(2L+1)$. No additional radial factors or
weights are applied to the pair products. Field coefficients represent
ordinary values of $W^{LM}(r)$, not $rW^{LM}(r)$.

## Example

```python
import numpy as np
from grid_lib.pseudospectral_grids.femdvr import FEMDVR
from grid_lib.pseudospectral_grids.gauss_legendre_lobatto import (
    GaussLegendreLobatto, Linear_map,
)
from tdmcscf.grid.spherical import SphericalMeanFieldBuilder

radial = FEMDVR(
    np.array([0., 2., 5., 10., 20., 40.]),
    np.full(5, 21),
    Linear_map,
    GaussLegendreLobatto,
)
builder = SphericalMeanFieldBuilder(radial, l_max=2)
orbitals = np.zeros((1,) + builder.orbital_shape, dtype=complex)
orbitals[0, :, builder.orbital_lm.index((0, 0))] = (
    2 * builder.r * np.exp(-builder.r)
)

fields = builder.build(orbitals)
W00 = fields.multipoles((0, 0))  # (n_LM, n_r)
action = fields.apply(orbitals, (0, 0))  # same shape as orbitals
```

Set `poisson_method="inverse"` or `poisson_method="solve"` when constructing
the builder to select grid-lib's radial Poisson linear-algebra path. Reuse the
builder as orbitals change: `fields = builder.build(new_orbitals)`.
It caches angular tables and radial response matrices. A field result keeps
the potentials from that build; later builds do not update previous results.

## Pair selection and action

`build(..., pairs=[(q, s), ...])` preserves the requested order. The default
contains all `q <= s`, ordered by q and then s. Results expose this explicit
list as `fields.pairs`; `fields.coefficients` has shape `(n_pairs, n_LM, n_r)`.

A stored pair also supplies its reverse through

$$
W_{sq}^{LM}=(-1)^M\bigl(W_{qs}^{L,-M}\bigr)^*.
$$

Both `multipoles((s, q))` and `apply(targets, (s, q))` reconstruct the reverse
when only `(q, s)` was stored. Complex off-diagonal potentials are preserved.

`apply` accepts one orbital `(n_r, n_lm)` or a batch
`(n_targets, n_r, n_lm)`. It computes the retained harmonic coefficients of
$W_s^q U_p$ and returns the same shape. This is the mean-field contribution
in the reduced radial representation after multiplication of the orbital
equation by r. No orbital-space Q projector, RDM contraction, or propagation
factor is included. Applying one pair at a time avoids allocating every
pair/target combination; callers can accumulate their RDM contractions.

## Fixed magnetic quantum numbers

Supply `orbital_m` to `build` to select the polar-only path. It is a sequence
of one integer per source orbital, or a scalar if all share the same m.
Use the same orbital array layout, with exact zeros outside each declared m.
The pair has $M=m_s-m_q$, so its azimuthal integral is performed analytically.

```python
fields = builder.build(orbitals, orbital_m=[0])
action = fields.apply(orbitals, (0, 0), orbital_m=[0])
```

For polar-only action, also supply the target orbitals' `orbital_m` to
`apply`. The output has $m_{\rm out}=m_{\rm target}+M$; channels outside the
retained orbital basis are projected out. Without target m metadata, `apply`
uses the general path. Both paths return the same dense channel layout;
the fixed-m path avoids azimuthal sampling and FFTs during evaluation.

The general path uses associated-Legendre transforms and FFTs on a
Gauss-Legendre-Fourier grid. The default angular grid resolves the complete
orbital product space, including pair multipoles through `2*l_max`, even when
the retained Coulomb expansion is smaller. A custom grid requires at least
`2*l_max+1` polar nodes and `4*m_max+1` azimuthal nodes.

## Scope and validation

The current radial implementation uses dense precomputed Coulomb response
matrices, with storage proportional to `(L_max+1)*n_r**2`. It assumes a fixed
real radial grid beginning at zero and free-space multipole boundary conditions.
No complex scaling or biorthogonal left/right orbital support is implemented.
The builder does not require or enforce orthonormality of its input arrays.

Tests compare construction with grid-lib's `compute_mean_field_einsum`, passing
`get_ybar(...)` as its argument named `y`. The conjugated field harmonic is
required for this multipole convention. Orbital action is independently checked
with `get_y(...)`. Additional tests cover analytic monopole and complex dipole
fields, quadrature normalization, pair reversal, and fixed-m/general agreement.

The transform/product/Poisson construction follows the approach described in
[Sato et al., Phys. Rev. A 94, 023405 (2016), Appendix E](https://link.aps.org/accepted/10.1103/PhysRevA.94.023405).
